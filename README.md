# PanitiaHub 🚀

**PanitiaHub** adalah aplikasi manajemen kepanitiaan modern berbasis Android yang dirancang untuk mempermudah koordinasi tim dalam menyelenggarakan acara. Dibangun menggunakan teknologi terbaru Android untuk performa yang cepat dan antarmuka yang responsif.

---

## ✨ Fitur Utama
Aplikasi ini menyediakan berbagai modul penting untuk kerja sama tim:
- 📊 **Dashboard Agenda:** Memantau semua acara aktif secara real-time.
- ✅ **Task Management:** Pembagian tugas yang jelas untuk setiap divisi.
- 💰 **Budget Tracker:** Pengelolaan anggaran masuk dan keluar secara transparan.
- 🏬 **Vendor Status:** Memantau progres kerjasama dengan pihak ketiga/vendor.
- 📞 **Contact Person (PIC):** Daftar kontak penting divisi untuk koordinasi cepat.
- 📅 **Attendance:** Sistem absensi rapat yang terintegrasi.
- 🛠️ **Inventory:** Pencatatan peminjaman alat dan perlengkapan.
- 🔗 **Link Collection:** Kumpulan link dokumen penting (Google Drive, Form, dll) dalam satu tempat.
- 🎨 **Design Templates:** Akses cepat ke panduan visual acara.

---

## 🛠️ Tech Stack
- **Bahasa:** Kotlin
- **UI Framework:** Jetpack Compose (Modern Declarative UI)
- **Design System:** Material Design 3
- **Database & Auth:** Firebase (Firestore & Authentication)
- **Architecture:** MVVM Pattern (Clean Architecture ready)

---

## 🚀 Cara Setup (Penting)
Karena alasan keamanan, file konfigurasi Firebase tidak disertakan dalam repositori ini. Ikuti langkah berikut untuk menjalankan project:

1.  **Clone Repositori:**
    ```bash
    git clone https://github.com/username-anda/PanitiaHub.git
    ```
2.  **Konfigurasi Firebase:**
    - Buat project baru di [Firebase Console](https://console.firebase.google.com/).
    - Tambahkan aplikasi Android dengan package name `com.example.panitiahub`.
    - Download file `google-services.json`.
    - Letakkan file tersebut di folder `app/` pada direktori project Anda.
3.  **Build Project:**
    - Buka project di Android Studio.
    - Sinkronkan Gradle (Sync Project with Gradle Files).
    - Jalankan aplikasi (`Run app`).
